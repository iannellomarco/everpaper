Updates & Support

How to install a new beta, how automatic updates will work after launch, and where to report problems.

During the private beta, Everpaper does not update itself. Each new beta arrives as a private download link. Install it over your current copy, as below. Automatic updates start with the first public release.

Installing a new beta#

  1. Finish or stop any recording, then quit Everpaper.
  2. Open the new disk image from your latest link and drag Everpaper into Applications. Choose Replace.
  3. Open Everpaper again. Your history, settings and models stay where they were.

Use the most recent link you were sent. Older links can stop working once a newer build is out. To see what changed, read the release notes.

Some betas also have an end date. A few days before it, the top of Settings tells you how long is left. After it, Everpaper won't start new meetings or journal sessions, but everything you've already recorded stays readable, searchable and exportable. Install the newest beta to record again.

Note

Coming from a Hindsight-branded release? The old update feed has been retired, so it won't offer Everpaper. Quit Hindsight, then install Everpaper from your beta link (or apply at everpaper.app/beta) into Applications. It uses the same data folder, so your history is kept. Then move the old Hindsight app to the Trash.

Automatic updates (after launch)#

Everpaper's update checks are already built in. Choose how they work in Settings → General → Updates (⌘,):

  • Off: no automatic checks.
  • Check only (default): Everpaper checks once a day and asks before downloading.
  • Check and download: a found update downloads in the background, ready to install.

No check runs while a meeting is recording.

Checking manually#

  • Everpaper → Check for Updates… in the app menu, or the same item in the Everpaper menu-bar icon
  • Settings → General → Updates → Check for Updates…
  • ⌘K, then Check for updates

During the private beta a check always finds nothing, because betas aren't published to the update feed. To see whether a newer beta exists, look at the release notes. Your copy's version is in Settings → About.

Updates and your meetings#

Everpaper never interrupts a recording to update. Update checks are paused while a meeting is recording, and an already-downloaded update will not relaunch the app mid-recording. Stop the recording and the update can go ahead. If you press Check for Updates… in Settings during a recording, Everpaper shows Finish recording before requesting another Everpaper release check. From the menus, the check simply doesn't run. Try again once the recording has ended.

Support and feedback#

Found a bug, or have an idea? Help → Everpaper Help or Help → View on GitHub opens the project on GitHub: github.com/iannellomarco/everpaper. Open an issue there to report a problem or request a feature.

Issues on GitHub are public. Don't paste transcripts, screenshots or anything else from your history. Describe the problem in words and include your build info: open Settings → About and press Copy build info, then paste it into your report. It lists the version, build and where the app is installed. If that location shows your Mac user name, remove it before posting. You can also see the version in Everpaper → About Everpaper.
